# 🌿 BioCan — Ecological E-Commerce Platform

[![Live Demo](https://img.shields.io/badge/Demo-Live_App-brightgreen?style=for-the-badge&logo=vercel)](https://bio-can.vercel.app/)
[![GitHub Repo](https://img.shields.io/badge/Code-Repository-blue?style=for-the-badge&logo=github)](https://github.com/Jorgetazones/BioCan)

A full-featured web application for browsing and purchasing ecological products. Built with modern web technologies, focusing on clean architecture, responsive user interface design, and seamless navigation.

🚀 **Live Demo:** [https://bio-can.vercel.app/](https://bio-can.vercel.app/)

---

## ✨ Key Features

- **Product Catalog:** Interactive gallery of ecological products with dynamic category filtering.
- **Shopping Cart System:** Real-time cart management (add, remove, and quantity updates).
- **Responsive UI:** Fully mobile-friendly layout optimized for all device sizes.
- **Fast Performance:** Optimized client-side routing and instant page loads.
- **Automated Deployment:** Continuous deployment pipeline powered by Vercel.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, JavaScript (ES6+), HTML5, CSS3
- **Tooling & Build:** Vite / Webpack
- **Deployment & Hosting:** Vercel
